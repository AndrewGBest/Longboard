# Getting help

| You want to | Go to |
|---|---|
| Ask how to do something, or show what you made | [Discussions](https://github.com/AndrewGBest/Longboard/discussions) |
| Say a website does not work with the remote | [A site report](https://github.com/AndrewGBest/Longboard/issues/new?template=site.yml) |
| Report something wrong in Longboard itself | [A bug report](https://github.com/AndrewGBest/Longboard/issues/new?template=bug.yml) |
| Suggest something | [An idea](https://github.com/AndrewGBest/Longboard/issues/new?template=idea.yml) |
| Report a security problem | Privately: see [SECURITY.md](SECURITY.md) |
| Make a site work better | Write a profile: [Longboard-Profiles](https://github.com/AndrewGBest/Longboard-Profiles) |

Before asking, the [README](README.md) has the buttons and what is known
not to work, and [docs/STATUS.md](docs/STATUS.md) has the detail.

This is a spare-time project with one maintainer. Answers can take a few
days.
